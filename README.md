# pricepilot-miniapp

Страница мини-приложения Telegram для бота PricePilot.

Здесь только интерфейс: секретов, кода бота и данных нет. Страница открывается из бота и обращается к нему по адресу из параметра `?api=`. Каждый запрос подписан Telegram и проверяется ботом.

Исходник страницы хранится в приватном репозитории бота (`webapp/index.html`), сюда копируется при обновлении.
